# 校园 Agent Harness

启动和环境配置见项目根目录 README 的“本地校园 Agent”部分。修改 Python 服务后需要重启 Harness。

## 执行边界

- 每进程最多同时执行 4 轮，繁忙时立即返回 `ai_busy`。
- 每轮最多 120 秒、12 次模型请求、24 次工具调用、180000 输入 token 和 12000 输出 token；单次模型请求最多 50000 输入 token、4096 输出 token，超时 45 秒。单次工具执行超时 25 秒。
- 历史最多保留最近 16 条消息，总计 24000 字符，包括历史引用映射；只有已经完成的问答进入后续历史。
- `ai_timeout`、`ai_budget_exceeded` 与普通上游错误分别返回。成功和失败均记录请求关联、耗时以及已经取得的 token 用量。中断请求可能拿不到模型最终用量。
- 浏览器断开或取消读取会取消上游流及 Agent 执行；失败轮次清理未完成的用户消息。已经成功提交的问答保留。同步网页读取线程可能继续到网络超时。

## 资料与引用

检索和读取会重新加载当前已发布资料，并关闭 SQLite 连接。标题与正文命中的摘录合并；网页去重仅依据本轮返回的资料，返回资料的来源 URL 仍可打开核实。

最终回答中的数字引用必须来自本轮实际打开的资料；引用的本地资料若在回答前修改或下架，会要求模型重试。返回的来源列表仅包含最终回答使用的引用。历史引用只用于重新查证，不能作为本轮的引用。流式重试会清空上一版临时答案。

这些检查保证引用编号与资料状态有效，不能证明每个事实都被引用原文支持；仍需要用实际校园问题评估回答准确率。

## 网页地址校验

网页连接严格拒绝内网、回环和保留地址，重定向也接受相同校验；实际连接使用已经检查的数字 IP，并保留原始 Host 与 TLS SNI，防止二次 DNS 解析绕过检查。网页读取不使用环境中的 HTTP 代理。

若系统 DNS 将域名全部解析到代理的 `198.18.0.0/15` 假地址，使用固定的 Cloudflare HTTPS DNS 服务 `https://1.1.1.1/dns-query` 获取真实公网 IPv4 地址，再校验并连接；结果缓存按 30 秒时间段划分。保留 IP 字面量不能触发此回退。DNS 服务不可达或返回非公网地址时拒绝读取，不放宽校验。该服务只接收域名，不接收问题或资料正文。

## 回归检查

在仓库根目录运行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s agent_harness/tests -v
node --test tests/*.test.mjs
node node_modules/typescript/bin/tsc --noEmit --incremental false
```

Python 测试使用真实 Pydantic AI 执行框架与模拟模型，网页、DNS 和资料库均隔离，不调用付费模型。Node 测试执行实际历史处理和聊天路由，模拟上游与持久化依赖，覆盖成功、预算耗尽、异常结束、超时及取消。
