# 西电知行前端视觉系统

## 设计方向

- 桌面采用左侧导航、约 640px 主内容流、右侧上下文栏。
- 手机采用顶部栏、单列内容、底部导航和悬浮发布按钮。
- 内容流参考 Threads：头像和正文并列、细分隔线、弱容器感。
- 个人主页和媒体网格参考 Instagram 的信息组织方式。
- Sheet、对话框、触控区域和移动端反馈沿用现有 React Aria 能力，使用轻量圆角和模糊顶栏。
- 西电知行使用自己的品牌色、Logo、中文文案与校园入口，不复制参考项目身份元素。

## 只读 UI 参考

本机参考仓库位于主项目同级的 `../references/twitter-clone`，来源为 `ccrsxx/twitter-clone`，当前检出提交 `62a9588`，许可证为 MIT。仅阅读并对照以下内容：

- `src/components/layout/main-layout.tsx` 与 `src/components/sidebar/sidebar.tsx`：桌面栏位、移动导航和发布入口；
- `src/components/home/main-container.tsx`、`src/components/home/main-header.tsx`：主流宽度和粘性页头；
- `src/components/tweet/tweet.tsx`、`src/components/tweet/tweet-stats.tsx`、`src/components/input/input-form.tsx`：帖子结构、互动行和发布器；
- `src/components/user/user-nav.tsx` 与 `src/components/user/user-header.tsx`：个人页封面、统计信息和标签栏；
- `src/components/view/view-parent-tweet.tsx`：回复线程层级；
- 对照 Tailwind 断点检查手机、窄屏和三栏桌面的布局行为。

参考仓库保持只读，不复制其 Firebase、认证、数据层、API、hooks 或状态管理。Munia 的 Prisma、API、React Query hooks、React Aria 和业务组件逻辑继续作为产品实现的唯一来源。

## 共用实现

- 壳层与导航：`src/components/AppShell.tsx`、`MenuBar.tsx`、`MobileTopBar.tsx`、`RightRail.tsx`。
- 页面标题：`src/components/ui/PageHeader.tsx`。
- 颜色、间距、半径和栏宽：`src/app/globals.css` 的 CSS tokens。
- 主流和评论：沿用 `Posts`、`Post`、`Comments`、`Comment` 与 `CommentReply`，只调整呈现层。
- 个人主页、媒体、发现、通知、私信和校园页面组合共用壳层与控件，不建立互不相关的页面视觉语言。

任何界面更新都要保留现有 Munia 数据流和业务行为；如果某个页面需要新交互，应继续接入现有 hooks、API 和 React Aria primitives。
