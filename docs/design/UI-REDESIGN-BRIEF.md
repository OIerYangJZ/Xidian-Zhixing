## 1. 产品是什么

西电知行是西安电子科技大学的校园社区，面向在校学生，用西电统一身份认证登录。核心板块有四个：

- **树洞**：发帖、评论、点赞、收藏，支持匿名发帖和自定义匿名昵称，帖子分版块，有话题标签、置顶、"进行中 / 已解决 / 已结束"等状态。
- **校园**：课表、考试、今日日程、校园服务外链、校园地图，以及统一认证中心（校园网自服务、宿舍水机等子系统的登录）。
- **AI（小电）**：校园问答助手，回答时附上引用来源。
- **私信与通知**：一对一私信（陌生人需要先发私信请求）、通知中心。

此外还有内容治理：举报、审核状态（待审核 / 被拒绝）、禁言、封禁以及封禁申诉，还有一个管理后台。

## 2. 三个客户端

| 客户端 | 技术 | 对应清单 |
|---|---|---|
| Web（手机和电脑浏览器都要用） | Flutter Web | 第一部分 |
| 微信小程序 | 原生小程序（WXML/WXSS，单位是 rpx） | 第二部分 |
| Android App | Flutter 原生 | 第三部分 A 节 |

三端功能大体一致但并不完全相同，差异见第三部分 A.4。**希望三端共用一套设计语言**（颜色、字体、组件形态统一），各端再按平台习惯调整布局。

## 3. 希望设计方交付什么

1. **设计系统**：字体和字号阶梯、圆角、间距、阴影和层级，以及一套**颜色 token 的结构**（背景、表面、主色、文字、分割线、状态色等各有哪些角色）。本次只需用一套中性配色把设计做出来，浅色和深色各一版。**具体配色方案不在本次范围**，见 §4。
2. **组件**：帖子卡片（含所有标记，见第一部分 §2.5、第二部分 §0）、评论、按钮、输入框、开关、列表项、底部表单、弹窗、提示条、徽标和未读数、头像（含匿名头像）、空状态、加载、出错重试。
3. **页面**：清单里的每个页面，至少覆盖手机和电脑两种宽度。Web 的断点是 600 / 960 / 1200，另有局部 900（见第三部分 C.3）。
4. **状态**：每个页面的加载中、空、出错、未登录、无权限、提交中；内容本身的状态：待审核、被拒绝、已删除、匿名、置顶、已解决；账号状态：禁言、封禁（见第三部分 C.7）。

## 4. 硬约束（设计时就要满足）

- **中英双语**：所有界面文字都要有中文和英文，设计时给英文留够长度。
- **浅色和深色**：三端都要支持。
  - **Web**：跟随系统，不提供手动开关。
  - **小程序、Android**：默认跟随系统，另外提供手动切换（跟随系统 / 浅色 / 深色）。
- **配色主题**：用户可以切换配色主题，这个功能要保留。三端统一使用 Web 现有的 4 套主题（名称和色值见第三部分 B.1），小程序和 Android 会同步过去。
  - **本次不设计配色**。UI 定稿后会单独设计配色方案，所以颜色必须全部走 token，不能在组件里写死颜色，保证换一套配色时不用改组件。
  - 设置页里要给"配色主题"留出位置，至少能容纳 4 个选项。
- **不能依赖外网资源**：生产服务器没有外网，字体、图标、图片必须随包分发，不能用 Google Fonts、CDN、在线图标库（见第三部分 C.4）。已打包的中文宋体两款约 43MB，新设计如果换字体，请考虑包体积。
- **小程序平台限制**：单位用 rpx；要避开右上角胶囊按钮和底部安全区；tabBar 用原生实现，图标是图片资源（第二部分 §4）。
- **Flutter Web 是画在 canvas 上的**：不存在"CSS 效果"，设计只要能用 Flutter 组件实现就行。

## 5. 不要做的事（上一次改版踩过的坑）

上一次改版视觉上改好了，却悄悄丢了很多功能，最后整版被回滚。请特别注意：

- **不要用示例数据占位**：设计稿里可以有示例内容，但要明确标成示例。上一版把设计稿里的示例昵称、"7 个关注者"、示例帖子直接写进了正式界面。
- **不要画没有对应功能的按钮**：每个可点的元素都要能对应到清单里的某个操作。清单里没有的新功能可以提，但要单独列出来，由产品决定做不做。
- **不要删功能入口**：尤其是收藏、注销账号、退出登录、深浅色切换、配色主题、语言切换、黑名单、帖子上的匿名 / 置顶 / 版块标记、小程序的帖子布局选项。三份清单开头各有一张"必须保留"的核对表。

## 1. 导航结构

### 1.1 启动时进哪个页面（`app.dart` → `_initialPage`）
1. 已登录 + 被封禁 → **被封禁申诉页**（`features/auth/banned_account_page.dart`）。没有外壳、没有导航，只剩申诉和退出登录。
2. 已登录（未封禁）→ **主外壳 HomeShell**（`widgets/home_shell.dart`）。
3. 没有用户会话，但管理后台开关打开（编译参数 `ENABLE_ADMIN_CONSOLE`，默认关）且管理员已登录 → **管理后台**（`features/admin/admin_portal_page.dart`）。
4. 其他情况 → **登录页**（`features/auth/login_page.dart`）。
- 统一认证回跳：URL 带 `?xidianAuthAttempt=...` 时，登录页自动完成登录，然后进主外壳。
- 帖子深链：URL 带 `?postId=...`（只在同一浏览器会话里有效）时，主外壳加载完会自动打开那篇帖子的详情。打开详情时 URL 写入 `postId`，关闭后清掉。

## 2. 各页面

### 2.1 登录页 `features/auth/login_page.dart`
- **用途**：通过西电官方统一身份认证（SSO）登录。没有账号密码表单。
- **显示内容**：品牌字标（「知」+「西电知行」）；标语「让校园里的真实声音被听见」；补充说明；宽屏另有两条卖点（「阅读优先」「跨屏可用」及各自描述）；「欢迎回来」；说明「前往西电官方统一身份认证页面完成登录」。
- **操作**：
  - 「前往西电官方认证」主按钮 → 在当前窗口跳到 SSO 页面
  - 中/EN 语言切换（宽屏在表单右上，窄屏在品牌头部）
  - 「管理员后台登录」（只有管理后台开关打开时才出现）→ 管理员登录页

## 3. 全局交互

### 3.1 提示和确认
- **提示（SnackBar）**：几乎所有操作的成功和失败都用底部轻提示反馈（格式「操作失败：…」「已收藏」「评论已发送」等）。取消收藏的提示带「撤销」按钮。

## 4. 小程序平台约束

- **单位**：样式基本用 `rpx`（750 设计稿宽）；自定义导航相关的顶栏高度、内边距用运行时 `px`（`navTop`/`navHeight` 来自胶囊按钮位置）。
- **自定义导航**：8 个页面（见 §1.4）。右上角是微信胶囊按钮（不可遮挡、不可改），顶栏内容须在胶囊左侧并与胶囊垂直居中对齐。自定义导航页的系统下拉刷新体验不同，树洞使用 scroll-view 内置 refresher。
- **Safe-area**：`env(safe-area-inset-bottom)` 用于：全局 `.safe-bottom`、抽屉、树洞悬浮按钮、发帖底部工具栏、帖子详情评论栏、我的页、聊天输入栏、AI 对话输入栏。
- **TabBar**：原生 TabBar（`style: v2`），只能改文字、图标 PNG、颜色，不能自定义形状或加中间凸起按钮（除非改为自定义 TabBar，需要额外开发）。图标需为本地 PNG。
- **深色模式**：`app.json` **未开启** `darkmode: true`；深色由页面根节点 class（`color-mode-dark`）+ 运行时 `setNavigationBarColor` / `setTabBarStyle` / `setTabBarItem` 实现。原生组件（ActionSheet、Modal、Toast、picker、switch、键盘）不会跟随应用内深色设置，只跟随系统。部分页面 json 写死了浅灰导航色（编辑资料、账号安全、隐私、黑名单），运行时会被覆盖。
- **主题**：页面根节点 class `theme-<主题> color-mode-<light|dark> lang-<zh|en>`，颜色通过 CSS 变量（`--app-background`、`--app-surface`、`--brand-primary`、`--brand-deep`、`--text-secondary`、`--app-divider` 等）下发；分区色由服务器分区名映射。
- **原生交互组件大量使用**（设计时需接受其系统外观或另做自定义组件）：`wx.showActionSheet`（帖子更多、评论长按、评论排序、举报理由、聊天长按、聊天屏蔽）、`wx.showModal`（含 `editable: true` 可输入弹窗：举报描述、问 AI、升级理由、注销原因、所有后台备注）、`wx.showToast`、`wx.showLoading`、`picker`（周次、日期、主题、性别、反馈类型）、`switch`。ActionSheet 最多 6 项。
- **图片**：`wx.chooseMedia`（回退 `wx.chooseImage`）选图并压缩；`wx.previewImage` 全屏预览；HTTP 图片先 `wx.downloadFile` 到本地再显示（加载会有延迟）。
- **分享**：仅帖子详情支持"转发给朋友"（`onShareAppMessage` + `button open-type="share"`）；未实现朋友圈分享（`onShareTimeline`）。
- **web-view**：只能打开白名单域名；web-view 页面上无法叠加自定义 UI。
- **其它 API**：`wx.getMenuButtonBoundingClientRect`、`wx.getWindowInfo`、`wx.getAppBaseInfo`、`wx.getDeviceInfo`、`wx.getAccountInfoSync`（版本号）、`wx.getUpdateManager`、`wx.setClipboardData`、`wx.pageScrollTo`、`wx.createSelectorQuery`、`wx.nextTick`、`wx.reLaunch / redirectTo / switchTab / navigateTo / navigateBack`。基础库版本 `3.16.1`（`project.config.json`）。
- **本地存储键**（设计相关）：`token`、`colorTheme`、`displayMode`、`treeholePostLayout`、语言、`searchHistory`（8 条）、`aiHistory`（30 条）、`campusAuthStates`、`campusScheduleUpdatedAt`。

### A.4 移动端 vs Web 功能差异汇总
- 移动端没有：校园（campus / 认证中心 / 服务详情）、校园 AI、封禁账号页（`lib/features/auth/banned_account_page.dart` 含申诉流程）、Android 下载页、举报详情页、表情设置页、屏蔽列表、Web 的讨论流布局和宽屏分栏。
- 移动端特有：底部 3 Tab + 滑动切换、底栏随滚动隐藏、返回键双击退出、长按保存图片到相册、Android 应用内更新、私信长按菜单（转发 / 详情 / 批量撤回）。
- 视觉体系不同：
  - 移动端 `MobileTheme`：卡片 / 输入框圆角 12，按钮圆角 14，iOS 风格。
  - Web `AppTheme`：圆角 2–6，按钮用深色面板配色。

## C. 重设计硬约束

### C.1 国际化（i18n）
- ARB 文件：`flutter_app/lib/l10n/app_zh.arb`（模板）和 `app_en.arb`，**只有 zh / en 两种语言**，各约 70 个 key，生成代码在 `lib/l10n/generated/`（配置见 `flutter_app/l10n.yaml`）。
- 主要写法是 `uiText(context, zh:, en:)`，定义在 `lib/core/l10n/ui_text.dart`，Web 端有 33 个文件、约 390 处调用。还有 `localizedAlias`，把服务端返回的“匿名同学 / 匿名用户”显示为 Anonymous；`localizedChannel`，把“全部 / 未分类 / 其他”翻成英文，其余频道名属于用户内容，不翻译。
- 英文模式下字体会整体切换（B.2），版式要能同时容纳中英文的长度差异。
- 现状缺口：
  - 移动端几乎全部硬编码中文，包括底栏标签“首页 / 消息 / 我的”。
  - 小程序 `utils/i18n.js` 里有 zh-CN / zh-TW / en 三套词典，但 `getLanguage()` 只会返回 `en` 或 `zh-CN`。
- 测试断言英文界面不得出现中文字样：`flutter_app/test/ui_responsive_test.dart`，例如断言不出现“内测”“非官方”。

### C.2 浅色 / 深色
- Web：`ThemeMode.system`，每个主题都有 light 和 dark 两套 `EditorialColors`（`lib/app.dart`）；启动屏 `index.html` 带 `prefers-color-scheme: dark` 样式，`color-scheme: light dark`。
- 移动端：**写死浅色**（A.0）。
- 小程序：
  - 显示模式可选 跟随系统 / 浅色 / 深色，存为 `displayMode`；通过 `.color-mode-dark` 类加上 `wx.setNavigationBarColor` / `wx.setTabBarStyle` / `wx.setTabBarItem` 生效（`utils/theme_i18n.js`）。
  - `app.json` 没开 `darkmode`，也没监听 `wx.onThemeChange`：“跟随系统”只在页面调用 `applyThemeAndLanguage` 时读取一次。
  - 深色下导航栏和 tabBar 是纯黑背景 + 白字。

### C.4 生产 CSP 与离线环境
- CSP 定义在 `deploy/production/nginx-treehole-https.conf.template:39` 和 `nginx-container.conf:20`，两处一致：
  `default-src 'self'; script-src 'self' 'unsafe-inline' 'wasm-unsafe-eval' https://www.gstatic.com; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; font-src 'self' data:; media-src 'self' blob:; connect-src 'self' https://www.gstatic.com; worker-src 'self' blob:; frame-ancestors 'self'; object-src 'none'`。
  另外还有 `Permissions-Policy`（禁用定位、麦克风、摄像头等）和 `X-Frame-Options: SAMEORIGIN`。
- 由此得出的约束：
  - **字体、图片、样式只能来自同源或 data:/blob:**，不能用 Google Fonts、图标 CDN 或第三方图片。
  - 服务器没有外网（见 `CLAUDE.md`），所以所有资源都必须打进包里自带。
  - 现有中文字体很重（约 43MB，STSong + STZhongsong），这是 Web 首屏加载的成本。
- `scripts/build_web_production.sh` 用 `flutter build web --release --no-web-resources-cdn` 构建，CanvasKit 由自己的服务器提供。脚本注释写着这样就可以去掉 gstatic 放行，**但 CSP 里目前仍保留了 `https://www.gstatic.com`**。

### C.5 小程序约束
- 尺寸单位：主要用 rpx（`app.wxss` 里约 156 处），个别地方用 px（导航栏头像 44px）。
- **用的是原生 tabBar**：只有 3 项（树洞 / 校园 / AI），没有 `custom-tab-bar`。因此图标只能是 PNG；选中图标按“主题 × 深浅”各做一套，通过 `setTabBarItem` 替换。
- 页面：42 个，没有 `subPackages`。`app.json` 设置了 `style: v2`、`lazyCodeLoading: requiredComponents`。仓库里没找到关于包体积上限的说明；目前 `miniprogram/` 目录约 1.4MB。
- 字体：只能用系统字体（B.2）。全局只注册了一个组件 `radio-drawer`（`miniprogram/components/radio-drawer/`）。

### C.6 无障碍现状
- `Semantics` 只出现在 5 个共享文件里：`core/widgets/{app_surfaces,async_page_state,language_toggle,theme_dropdown}.dart`、`lib/widgets/image_gallery.dart`。
- 移动端：`Semantics`、`semanticLabel`、`tooltip` 都是 0 处；Web 其他页面合计约 33 处 `tooltip` / `semanticLabel`。
- **没有对比度测试**，也没有适配字号缩放（`textScaler`）的代码。
- Web 控件保证了 44–48 的最小点击区域；小程序按钮 `min-height: 44rpx`。

### C.7 需要有视觉状态的内容规则
- **匿名**：
  - 匿名帖用印章头像（SealAvatar，取别名首字），点头像不能进主页。
  - 可以自定义匿名昵称或随机生成；服务端返回的“匿名同学 / 匿名用户”在英文下显示为 Anonymous。
  - 小程序有 `.anonymous-badge` 样式。
  - 楼主评论带“洞主”标签。
- **帖子属性**：
  - 状态：进行中 / 已解决 / 已结束，定义在 `lib/models/post_item.dart`。
  - 置顶：一级用户可设时长，界面显示“置顶”标签。
  - 可见范围：所有人可见 / 仅自己可见（`isPrivate`）。
  - 可关闭评论（`allowComment`）、关闭私信（`allowDm`）。
- **用户等级**：一级 / 二级，可以申请升级，申请后有审核中的状态。
- **私信规则**：
  - 对方回复或关注你之前，你只能发一条消息，界面有警告横幅。
  - 屏蔽 / 被屏蔽：会话上有“已屏蔽”标签。
  - 可在隐私设置里关闭陌生人私信。
  - 只能撤回 2 分钟内的消息，撤回后显示占位文字。
  - 发送失败可点击重试。
- **审核**（管理端）：
  - 帖子 / 评论：待审核 / 已通过 / 已驳回 / 风险。
  - 图片：待审核 / 已通过 / 已拒绝 / 风险项。
  - 举报：待处理 / 已处理 / 已关闭，处理动作有删除内容 / 封禁用户 / 标记误报。
  - 举报原因共 7 类（见 A.2 第 3 页）。
- **封禁**：
  - Web 有专门的封禁页 `lib/features/auth/banned_account_page.dart`：显示“账号已被封禁”，说明封禁期间不能发帖、评论、私信或用助手；可以提交申诉，申诉有“审核中 / 未通过”状态，某些情况下必须改用邮件申诉。
  - `AuthStore.isBanned` 为真时，Web 只渲染这个页面（`lib/app.dart:100`）。
  - **移动端和小程序在用户侧都没有找到封禁或禁言的界面**。
  - 禁言只在社区规范文字里提到，分 1–7 天、7–30 天和永久封禁三档（`features/legal/community_guidelines_page.dart`）。
- **注销账号**：流程是 申请 → 重新统一认证 → 管理员审核 → 停用，之后可申诉恢复；Web 的“我的”在申请状态为 pending 时会禁用操作（`features/profile/profile_page.dart:316`）。
- **用户侧的审核中 / 被驳回状态**：移动端发帖后直接提示成功，没看到“审核中”或“被驳回”的展示。Web 的举报详情页有“正在获取最新审核结果”（`features/me/report_detail_page.dart:59`）。
