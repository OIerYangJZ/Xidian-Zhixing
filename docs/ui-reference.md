# UI reference

The read-only reference checkout is a sibling of this repository at `../references/twitter-clone` (`ccrsxx/twitter-clone`, MIT, commit `62a9588`). Keep it outside the Munia repository and do not merge, fork, or modify its files.

Use it to compare the desktop three-column shell, mobile bottom navigation, feed width and spacing, post and composer layout, profile header and tabs, thread replies, and responsive breakpoints.

Only presentation is in scope: DOM structure, Tailwind/CSS, responsive behavior, and interaction layout. Do not copy Firebase, authentication, APIs, data models, or state management. Keep Munia's existing business logic, hooks, APIs, Prisma schema, and data access as the product foundation.
